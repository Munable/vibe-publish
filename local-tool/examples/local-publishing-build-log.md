This is a real local-development check of the forum's publishing boundary.

Today I verified three things from an ordinary member account:

- the browser composer could not create a topic;
- the local tool requested only permission to create topics and replies;
- the exact text stayed visible until I explicitly confirmed the send.

The server still owns permissions, rate limits, blocked-word checks, and moderation. The local review is useful friction, not proof that a client cannot be modified.
